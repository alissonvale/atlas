# Anexos

Índice dos materiais usados para construir o Atlas.

## A receber

- Descritivo do método.
- Planilhas de contexto.
- Outros materiais, exemplos, documentos ou notas.

## Como registrar anexos

Quando um material for recebido, registrar aqui:

- nome do arquivo;
- tipo de material;
- origem;
- propósito na jornada;
- principais conceitos extraídos;
- decisões ou memórias derivadas.

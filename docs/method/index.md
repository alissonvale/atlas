# Método Atlas

Esta seção será a fonte canônica do método Atlas.

Páginas prováveis, a confirmar após leitura dos materiais:

- visão geral;
- princípios;
- modelo conceitual;
- áreas de sustentação;
- papéis e responsabilidades;
- cadências;
- artefatos;
- políticas explícitas;
- métricas e sinais de saúde do produto.

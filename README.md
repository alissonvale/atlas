# Atlas

Atlas é uma jornada de construção de um método de gestão voltado para a sustentação de produtos de software.

O método será desenvolvido de forma análoga à jornada Ariad: primeiro como linguagem e documentação canônica, depois como práticas, templates, anexos e possíveis mecanismos operacionais.

## Estado inicial

Esta pasta foi criada como repositório local da jornada. O conteúdo canônico ainda será consolidado a partir do descritivo do método, planilhas e demais anexos fornecidos pelo Alisson.

## Estrutura inicial

- `docs/index.md` — mapa da documentação.
- `docs/project/briefing.md` — briefing vivo da jornada.
- `docs/project/roadmap/index.md` — roadmap inicial.
- `docs/method/` — documentação canônica do método Atlas.
- `docs/adoption/` — materiais futuros de adoção e aplicação.
- `docs/operations/` — práticas, cadências, checklists e mecanismos de sustentação.
- `docs/attachments/` — índice dos anexos e materiais de contexto.
